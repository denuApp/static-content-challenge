# Static Content challenge
## Acme Co.

### Link to a live deployment: https://static-content-challenge-client.onrender.com

## Description
This project is a web application that consists of a Node.js/Express backend and a React frontend, which allows for dynamic visualization of static content.

## 🚀 Applied Tecnologies

### Backend
- Node.js
- Express
- CORS
- fs-extra
- gray-matter
- marked

### Frontend
- React
- Axios
- Tailwind CSS
- Typography Plugin

## Getting Started

### 📋 Prerrequisitos

- Node.js (v14 o superior)
- npm (v6 o superior)
- Git

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/denuApp/static-content-challenge.git
2. Install dependencies:
    ```bash
    npm install
3. Start the application:
    ```bash
    npm run dev
